起因是手腕疼。医生说是劳损，建议我少用鼠标。

用了一个月的纯键盘工作流之后，我把这套键位固定了下来。记录一下。

## 三层结构

我把所有快捷键分成三层，**只有第一层需要肌肉记忆**：

```text
第一层（无修饰键）
  几乎不用 —— 会干扰正常输入

第二层（单修饰键）
  ⌘ / Ctrl + 单键：高频操作（保存、搜索、切换标签页）

第三层（组合键 / 引导键）
  Leader 键 + 序列：低频但重要的操作（重命名、分屏、格式化）
```

关键洞察：**第三层不需要记忆，因为它有提示**。我用 `⌘K` 当引导键，按下去会弹出所有可用命令，输入几个字母就能筛。这样「我记不住快捷键」这个问题就消失了。

> [!TIP] 好记的法子
> 与其背 `⌃⌥⇧F` 这种四键组合，不如用「引导键 + 搜索」。前者考验记忆，后者考验打字。

## 具体改了哪些

| 操作 | 原来 | 现在 |
| --- | --- | --- |
| 全局搜索 | `⌘⇧F` | `⌘K` |
| 切换文件 | `⌘P` | `⌘P`（保留） |
| 终端 | `⌃\`` | `⌃\``（保留） |
| 关闭标签 | `⌘W` | `⌘W`（保留） |
| 格式化 | `⌘⇧I` | `⌘K F` |
| 重命名 | `F2` | `⌘K R` |
| 分屏 | `⌘\` | `⌘K \` |

规律：**保留所有「单手可完成」的快捷键，把需要双手扭曲的都收进引导键里**。

## CapsLock 改成了什么

CapsLock 是键盘上最没用的键，位置却是最好的。我把它改成了：

- 短按：`Esc`（Vim 用户狂喜）
- 长按：`Ctrl`

```text
短按 CapsLock → Esc
长按 CapsLock → Ctrl（配合 HJKL 变方向键）
```

改完第一周很难受，第二周就再也回不去了。

## 一点数据

```text
改造前：日均鼠标移动距离约 1.8 km（估算）
改造后：约 0.6 km
手腕疼痛：从每天都有 → 一周偶尔一次
适应期：约 10 天
```

## 给想改的人的建议

1. **一次只改一个键**，同时改五个你会崩溃
2. **保留出错的退路**，至少前两周别删掉默认键位
3. **做一张备忘卡贴在显示器旁边**，比反复查配置快
4. **接受「变慢」** —— 前两周效率一定会下降，这是投资不是损失

> [!NOTE] 最重要的原则
> 如果某个改动两周后还需要你「刻意想起来才能用」，那它大概率不适合你。
> 好的键位设计是让你忘掉键位本身。

现在敲代码基本不碰鼠标了。唯一的问题是，用别人的电脑时会显得特别笨拙。
